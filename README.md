## Project Overview

This project focuses on predicting car prices using Machine Learning. The dataset contains various features related to cars, including brand, model year, kilometers driven, fuel type, transmission, owner type, engine capacity, maximum power, mileage, and number of seats.

A Random Forest Regression model is used to predict car prices based on these features.

---

## Objectives

- Explore and understand the car dataset
- Perform Exploratory Data Analysis (EDA)
- Analyse car price distributions and patterns
- Preprocess categorical features
- Train a Machine Learning regression model
- Predict car prices
- Evaluate model performance
- Analyse feature importance
